# Личный кабинет студента

Интерактивный учебный прототип: расписание, успеваемость по 100-балльной шкале, профиль, заявления и справки, мессенджер, новости и мероприятия. Интерфейс адаптирован для компьютера и телефона.

## Посмотреть

- Сайт после включения GitHub Pages: https://AlimPros.github.io/student-cabinet/
- Витрина мобильных экранов: https://AlimPros.github.io/student-cabinet/mobile-preview.html
- Исходный код: [source.zip](source.zip). Распакуйте архив, чтобы получить исходные папки `src/`, `tests/` и сборщик.

## Вход и ограничения

Для входа в учебный прототип используйте один из демонстрационных аккаунтов.

| Аккаунт | Логин | Пароль |
|---|---|---|
| Студент | student | lk-demo-2026 |
| Жюри | jury | jury-demo-2026 |

Форма проверяет пароль в браузере. Оба аккаунта открывают один учебный профиль.

Все учебные данные — демонстрационные. Изменения сохраняются в localStorage текущего браузера. Серверной базы, изоляции пользователей и настоящей отправки заявок в деканат нет. Маскирование полей и настройки безопасности демонстрируют интерфейс, но не обеспечивают защиту реальных данных. Не вводите реальные персональные данные и пароли.

## Исходники и сборка

После распаковки `source.zip` откройте папку `student-cabinet`:

```sh
python3 build.py
python3 -m http.server 8000 --directory src
```

Исходники: `src/index.html`, `src/assets/app.js`, `src/assets/zk.js`, стили в той же папке. Сборщик создаёт два самостоятельных HTML-файла. Для обновления сайта загрузите `Личный-кабинет.html` как `index.html`.

Проверки: `sh tests/run.sh` и `sh tests/run.sh dist` (требуется Google Chrome на macOS). На версии перед публикацией прошли 114 проверок для компьютера и 115 для телефона; это функциональные проверки прототипа, не аудит безопасности.
