# Личный кабинет студента

Учебный прототип объединяет повседневные задачи студента. Можно узнать время ближайшей пары, посмотреть баллы по предметам и заказать справку об обучении.

**[Открыть кабинет](https://campusdesk-app.github.io/)** · [Репозиторий на GitHub](https://github.com/campusdesk-app/campusdesk-app.github.io) · [Скачать исходники (ZIP)](https://github.com/campusdesk-app/campusdesk-app.github.io/raw/refs/heads/main/source.zip)

## Демо-вход

| Для кого | Логин | Пароль |
|---|---|---|
| Жюри | `jury` | `jury-demo-2026` |
| Студент | `student` | `lk-demo-2026` |
| Студент 2 | `student2` | `lk-demo-02` |
| Студент 3 | `student3` | `lk-demo-03` |

Все четыре пары открывают один учебный профиль. Для показа с исходными данными откройте сайт в новом приватном окне.

## Что можно попробовать

- **Главная и расписание.** На главной видна ближайшая пара. В расписании можно сменить день, посмотреть аудиторию и преподавателя, добавить своё занятие.
- **Учёба.** Общий рейтинг по шкале до 100, баллы по предметам, посещаемость, зачётка и сессия.
- **Профиль и документы.** Учебные сведения, студенческий билет, заказ справки, подача заявления и архив. Для демонстрации откройте «Профиль» → «Справки» → «Справка об обучении». Отправьте заказ в электронном формате. В «Моих заявках» появятся номер и статус, а через несколько секунд — кнопка «Открыть справку».
- **Уведомления и настройки.** Доступны учебные чаты, новости и мероприятия, смена темы, крупный текст и уменьшение анимации. Для выхода откройте настройки с главной страницы.

## Запуск на компьютере

Для просмотра опубликованного кабинета достаточно браузера. Чтобы запустить исходники локально, скачайте архив по ссылке выше, распакуйте его и откройте терминал в папке `student-cabinet`, рядом с `build.py`. Понадобится Python 3.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory src
```

Откройте [локальную страницу](http://127.0.0.1:8000/). Остановка сервера — Ctrl+C. Для отдельного HTML-файла выполните `python3 build.py` в той же папке и откройте `Личный-кабинет.html`.

## Данные и ограничения

Исходные расписание, профиль, оценки и переписки заданы в файлах прототипа. Заявки, сообщения, личные занятия и настройки сохраняются в localStorage — хранилище этого сайта в конкретном браузере. Они переживают перезагрузку и выход. В том же браузере все демо-входы увидят сохранённые изменения. На другом устройстве или на другом адресе сайта будет отдельная копия.

Пароль проверяет код, загруженный в браузер. Серверной авторизации и разграничения личных данных нет. Используйте демонстрационные данные. Заказ справки моделирует смену статусов, а переписка — ответы собеседников. Заявки и сообщения в вуз не отправляются.
